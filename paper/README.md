# Research Paper Manuscript & Supporting Artifacts

This directory contains the Springer LNCS (`llncs`) LaTeX manuscript, bibliography, experimental tables, and high-resolution figures for:

> **Contextual Data Augmentation for Imbalanced Multi-Label Classification of MITRE ATT&CK Techniques Using Domain-Adapted BERT**  
> **First / Submitting Author:** Tan Phat Nguyen (Faculty of Information Assurance, FPT University, Ho Chi Minh City, Vietnam)  
> **Milestone:** Research Abstract officially **Accepted** at *The 1st International Conference on Electrical, Electronics and Intelligent Systems 2026 (ICEEIS 2026 — IEEE Xplore Track, Microsoft CMT Submission ID: #228, Aug 17, 2026)*; extended full paper formatted in **Springer LNCS** ([`main.tex`](./main.tex)).

## Directory Contents

- [`main.tex`](./main.tex) — Complete Springer LNCS LaTeX manuscript source.
- [`references.bib`](./references.bib) — BibTeX bibliography (25 peer-reviewed references covering CTI automation, domain-adapted transformers, CDA, Focal Loss, and long-document encoders).
- [`figures/`](./figures/) — All experimental plots organized by benchmark (`tram1/`, `tram2/`, `rcATT/`).
- [`tables/`](./tables/) — Consolidated Markdown and LaTeX tables reproducing Tables 1–5 of the manuscript.
